# UNP_ML_REGRESSION_PROJECT_APPLIANCE_ENERGY_CONSUMPTION_PREDICTION_USING_PYTHON

I did this project in collaboration with UNP (United Network of Professionals). This group project focuses on developing a machine learning approach to predict household appliance energy consumption through data preprocessing, exploratory data analysis, statistical analysis, multicollinearity assessment, and feature selection using Python. Project Overview Household energy consumption is influenced by several environmental factors, making its analysis and prediction an important application of data-driven techniques. This project focuses on predicting household appliance energy consumption using machine learning and exploring the relationship between energy usage and environmental conditions. The study uses household energy consumption data containing appliance readings and various environmental parameters, including indoor and outdoor temperature, relative humidity, atmospheric pressure, and wind speed. The target variable, "Appliances", represents the energy consumption of household appliances.

Methodology The project follows a structured data science and machine learning workflow:

Data Understanding and Cleaning: Examining the dataset structure, identifying variables, and checking data quality, including missing values and duplicate records.
Exploratory Data Analysis (EDA): Analysing data distributions, identifying patterns, and understanding relationships among variables through statistical summaries and visualisations.
Outlier Analysis: Applying the Interquartile Range (IQR) method to identify and examine potential outliers.
Correlation Analysis: Investigating relationships between independent variables and appliance energy consumption using correlation matrices and heatmaps.
Multicollinearity Assessment: Using Variance Inflation Factor (VIF) to identify multicollinearity among predictor variables.
Feature Selection: Evaluating and refining the predictor variables based on correlation and VIF analysis.
Regression Modelling: Applying machine learning regression algorithms to develop predictive models for household appliance energy consumption.
Model Evaluation: Comparing model performance using appropriate evaluation metrics to assess predictive effectiveness.
Tools and Technologies : Language: Python Data Analysis: Pandas, NumPy Data Visualisation: Matplotlib, Seaborn Machine Learning: Scikit-learn Statistical Analysis: Statsmodels Environment: Jupyter Notebook

Project Objective

The overall objective is to apply statistical analysis and machine learning techniques to understand household energy consumption patterns, identify relevant influencing factors, and develop predictive models that can support better insights into residential energy usage.

Key Takeaways

This project demonstrates the practical application of data analysis, statistical techniques, feature selection, and regression modelling in addressing a real-world energy consumption prediction problem. It also highlights the importance of data quality, meaningful feature selection, and model evaluation in developing reliable machine learning solutions.
